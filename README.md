# Concept Projects — вариант Б

Многостраничный сайт в светлом «журнальном» стиле. Отдельный проект, со старым сайтом (`concept-projects`) не связан.

## Страницы

| Файл | Что на ней |
|---|---|
| `index.html` | Главная: первый экран, услуги, избранные проекты, основатель, этапы |
| `projects.html` | Каталог: фильтр по помещению, вид «плитка / список» |
| `project.html?p=<slug>` | Страница проекта: фото, характеристики, описание, материалы, детали, соседние проекты |
| `studio.html` | О студии и Умаре Рахимове, четыре этапа, лента работ |
| `services.html` | Три формата работы, калькулятор стоимости, этапы, вопросы |
| `contacts.html` | Телефоны, Telegram, Instagram, форма заявки |

Шапка, меню и подвал вставляются из `assets/js/site.js`, поэтому правятся в одном месте.

## Эффекты

- Заставка на главной (один раз за визит): шесть лопастей логотипа собираются, затем экран раскрывается шестигранником.
- Первый экран: слайдшоу из 5 проектов с миниатюрами, стрелками и полосой времени.
- Бегущая строка материалов (ускоряется при прокрутке), тёмный индекс всех работ, библиотека материалов с реальными счётчиками.
- Срезанный угол у фото (как лопасти логотипа), параллакс фото, заголовки поднимаются по словам.
- Страница проекта: широкая полоса фото и палитра цветов, извлечённая из фотографии.
- Плавные переходы между страницами (View Transitions; Chrome, Edge, Safari 18+).

## Где менять содержимое

Всё в `assets/js/data.js`:

- `SITE`: телефоны и ссылки.
- `RATES`: цены за м² для калькулятора. **Сейчас это заглушки, перед показом взять реальные цены у клиента.**
- `PROJECTS`: проекты. Поля `area` и `term` (площадь и срок) пустые, пока клиент не даст цифры. Пустые поля на сайте не показываются.

## Что нужно от клиента

1. Фото в высоком качестве, по 10–20 на проект (сейчас по одному кадру 512×640 из Instagram).
2. Реальные цены и сроки по трём форматам.
3. Площадь и сроки по каждому проекту.
4. Тексты о студии своими словами (сейчас черновик).
5. Отзывы, если хочет блок с ними.

## Форма заявки

Сервера пока нет: форма копирует текст заявки и открывает Telegram. Позже подключить Telegram-бота в обработчике `submit` в `site.js`.

## Языки

Пока только русский. Узбекский и английский добавим, когда тексты будут согласованы.

## Запуск

Любой статический сервер, например:

```bash
python3 -m http.server 5180
```
